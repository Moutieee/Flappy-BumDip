# Flappy BumDip

Play: https://moutieee.github.io/Flappy-BumDip/

## Live leaderboard

Click **CONNECT ACCOUNT**, sign in in the popup and confirm **CONNECT ACCOUNT**. Return to the game. Existing accounts keep their nickname; new accounts choose a unique nickname once.

The GitHub game and hosted game share the same leaderboard. Lifetime pickup Grams and escape bonuses count; purchases do not reduce rank. Scores start tracking after profile creation. Guests can play unranked.

The account session is remembered in this browser for up to seven days. Reconnecting uses the same saved nickname. Allow popups if your browser blocks the connection window.

Game saves (outfits, unlocks, collection and wallet) are still local to this browser and website. Previously earned portable-edition Grams are not imported into ranked totals.
